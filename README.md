## 🔧 نحوه اکسترکت فایل‌های چندتکه

اگر فایل بزرگ بوده و به چند قسمت تقسیم شده است:

1. **همه قسمت‌ها** (`.zip`، `.z01`، `.z02`، ...) را دانلود کنید
2. همه را در یک پوشه قرار دهید
3. فایل اصلی `.zip` را با نرم‌افزارهای زیر باز کنید:
   - **ویندوز**: 7-Zip، WinRAR
   - **مک**: Keka، The Unarchiver
   - **لینوکس**: `unzip filename.zip`
4. اگر رمز گذاشته باشید، هنگام اکسترکت رمز را وارد کنید

---

## 🧹 پاک کردن فایل‌ها

برای حذف ویدیوهای دانلود شده:

1. به ریپازیتوری خود بروید
2. وارد پوشه **`videos/`** شوید
3. پوشه ویدیوی مورد نظر را حذف کنید
4. Commit changes را بزنید

---

## 🔄 بروزرسانی فورک

برای دریافت آخرین تغییرات این ابزار در فورک خود:

1. به صفحه ریپازیتوری فورک شده خود بروید
2. روی دکمه **Sync fork** کلیک کنید
3. اگر گزینه **Update branch** فعال بود، آن را بزنید

---

## ❓ مشکلات رایج

| مشکل | راه حل |
|------|--------|
| دانلود انجام نمی‌شود | ویدیو ممکن است خصوصی یا حذف شده باشد |
| کیفیت پایین آمد | یوتیوب برای برخی ویدیوها کیفیت بالا را محدود کرده است |
| زیرنویس دانلود نشد | ویدیو ممکن است زیرنویس نداشته باشد |
| آپلود در گیت‌هاب شکست خورد | حجم ویدیو بیش از حد بزرگ است (بیشتر از 25 گیگ) |

## ⚠️ نکته مهم

این ابزار فقط برای استفاده شخصی و آموزشی طراحی شده است. از آن برای دانلود انبوه ویدیوها یا نقض قوانین کپی‌رایت استفاده نکنید.

فایل‌های ویدیویی دانلود شده در ریپازیتوری شخصی شما ذخیره می‌شوند. لطفاً با رعایت قوانین یوتیوب و گیت‌هاب از این ابزار استفاده کنید.
